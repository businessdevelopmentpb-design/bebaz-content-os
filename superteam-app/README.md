# PhotoBebaz BD Super Team OS

Standalone internal operating system for PhotoBebaz BD Super Team.

Production target:
- Vercel project: `photobebaz-bd-superteam`
- URL: `https://photobebaz-bd-superteam.vercel.app`

Embedded modules:
- BD Sales Control
- Error Control
- Bebaz Content OS

This app is independent from Lovable and uses the existing Supabase authentication/data sources.
